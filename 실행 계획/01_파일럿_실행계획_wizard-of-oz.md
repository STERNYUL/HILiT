# 0. 🔴 왜 컨시어지가 아니라 Wizard of Oz인가

## 0-1. 컨시어지의 함정

초안은 *"저희가 직접 편집해서 드립니다"* 였습니다. 이 방식은 **검증 대상이 어긋납니다.**

| | 코치가 인식하는 것 | 8주 뒤 결제하는 이유 |
| --- | --- | --- |
| **컨시어지** | *"편집 대행 서비스"* | 🔴 *"매주 알아서 해주니 편하다"* |
| **Wizard of Oz** | *"영상 올리면 나오는 도구"* | 🟢 *"내가 올리면 자동으로 나오니 좋다"* |

> **돈은 똑같이 내는데 이유가 다릅니다.** 대행 수요를 검증하고 앱을 출시하면, **검증했던 가치가 사라집니다** — 대행이 없어지니까요.

## 0-2. 전환의 핵심

**사람이 하는 일은 그대로 두고, 코치가 보는 경험만 바꿉니다.**

```
코치의 행동
  ① 폼에 영상 올린다        ← 앱과 동일
  ② 원생 이름을 선택한다     ← 앱과 동일
  ③ 링크로 결과를 받는다     ← 앱과 동일
  ④ 후보 중에서 고른다       ← 앱과 동일 (D2 원칙)

그 사이 (코치에게 보이지 않음)
  사람이 AI 흉내를 낸다
```

## 0-3. 이 방법이 답하지 못하는 것

> 🔴 **"AI가 정확한가"는 검증되지 않습니다.** 그건 **Gate A**가 실제 영상으로 모델을 돌려 확인할 일입니다.
>
> Wizard of Oz가 답하는 것은 **하나뿐**입니다 — *"이 결과물이 이 흐름으로 오면 클럽이 돈을 내는가."*
>
> **두 관문은 서로를 대체하지 않습니다.** 순서상 Gate A가 먼저 통과해야 제품이 성립합니다.

# 1. 사람이 지킬 규칙 — 🔴 이 파일럿의 성패

**AI가 못 하는 일을 사람이 해버리면 검증이 무의미해집니다.** 잘하면 안 됩니다.

## 1-1. 금지

| 🚫 하지 말 것 | 왜 |
| --- | --- |
| **예쁘게 자르기** | AI는 그렇게 못 한다. 컷 지점은 등장 구간 시작·끝에 기계적으로 맞춘다 |
| **자막·음악·효과 넣기** | 우리 기능 범위 밖. 넣으면 그 기대가 앱에 남는다 |
| **"이 장면이 좋겠다" 판단** | 🔴 **그건 코치가 할 일이다** — D2(사람이 선택)를 사람이 대신하면 안 된다 |
| **화질 보정 · 과도한 확대** | 확대 상한 **1.125배**(4K 가로)를 넘지 않는다 |
| 흔들림 보정 · 색보정 | 범위 밖 |
| **요청받고 다시 만들어주기** | 앱에서는 `다시 고르기`만 가능하다 |

## 1-2. 해야 할 것

| ⭕ | 방법 |
| --- | --- |
| 등장 구간 **기계적 추출** | 원생이 화면에 온전히 잡힌 구간만. 판단 없이 |
| **후보 30개를 보내고 코치가 고르게** | 완성본을 주지 않는다 |
| 크롭은 **중앙 배치까지만** | "크게 키우기"가 아니라 "가운데 놓기" |
| **처리 시간 지연 두기** | 즉시 회신하지 않는다 — 앱이라면 대기열이 있다 |
| 실패 케이스도 **그대로 보내기** | 잘 안 잡힌 것을 숨기지 않는다 |

> **1-1의 세 번째가 가장 어렵습니다.** 사람은 자연히 "좋은 장면"을 고르게 됩니다. **후보만 주고 선택은 코치에게 넘겨야** D2가 검증됩니다.

## 1-3. 작업 체크리스트 (매 건)

```
[ ] 등장 구간만 추출했다 — 잘 나온 것을 고르지 않았다
[ ] 후보를 30개 내외로 보냈다 — 완성본을 주지 않았다
[ ] 크롭이 1.125배를 넘지 않았다
[ ] 자막·음악·효과를 넣지 않았다
[ ] 처리 시간을 최소 30분 이상 두었다
[ ] 잘 안 잡힌 구간도 포함했다
```

# 5. 🔴 8주차 결제 제안

## 5-1. 방식

**말로 묻지 않고 결제 링크를 보냅니다.**

> *"다음 달부터도 이어서 받으시려면 월 15만 원입니다. 아래에서 결제하시면 계속 진행됩니다. 부담되시면 여기서 끝내셔도 괜찮습니다."*

| 🚫 | ⭕ |
| --- | --- |
| *"얼마면 쓰시겠어요?"* | **금액 제시 + 결제 링크** |
| *"계속 쓰실 거죠?"* | 아무 말 없이 **결제하는지 본다** |
| 할인 제안 | 정가로 한 번 |

## 5-2. 가격 근거

| 기준 | 금액 |
| --- | ---: |
| Veo 실측 (클럽당 연) | 약 190만 원 |
| 월 환산 | 약 16만 원 |
| **제안가** | **월 15만 원** |
| 원생 12명 클럽 매출 대비 | 8.3% |
| 원생 30명 클럽 매출 대비 | **3.3%** |

> ⚠️ 규모별로 부담률이 2.5배 차이 납니다. **어느 규모가 결제하는지가 타깃을 정합니다.**

## 5-3. 판정

| 결과 | 판정 | 다음 |
| --- | --- | --- |
| **2곳 이상 결제** | 🟢 통과 (강) | F16a·b 즉시 착수 |
| **1곳** | 🟡 조건부 | 결제한 규모로 타깃 재정의 |
| **0곳** | 🔴 미통과 | B2B 보류 · 개인 시장 집중 |

> 🔴 **0곳도 실패가 아닙니다. 개발 전에 알았다는 것이 값어치**입니다.
