## 1. 🔴 게이트를 적용하기 전에 — 게이트가 하나 부족하다

부록B의 게이트는 **농구 · 골프 · 테니스** 3종목을 가르기 위해 만들어졌다. 세 종목 모두 **촬영 문화가 이미 있다는 것이 전제**였기 때문에, 그 조건은 게이트에 들어가지 않았다.

**니치를 스포츠 밖으로 넓히는 순간 그 전제가 깨진다.**

> PRD §2-1: *"**1순위 기준은 원본 영상이 있는가**다. 앱에서 촬영하지 않으므로 원본이 없으면 제품이 작동하지 않는다."*

이 조건이 부록B 게이트에는 없다. 신설한다.

### 게이트 0 — 원본이 애초에 존재하는가

| | |
| --- | --- |
| **조건** | 그 니치에서 **삼각대를 세우거나 누군가 찍어주는 문화가 실재하는가** |
| **근거** | PRD §2-1 1순위 기준 · A-T2(앱이 촬영하지 않는다) |
| **왜 게이트인가** | 🔴 **원거리 촬영 가치가 아무리 높아도 원본이 없으면 0이다.** 곱셈에서 앞항이 0이면 뒤를 볼 필요가 없다 |

🔴 **게이트 0을 게이트 1보다 앞에 둔다.** 순서가 중요하다 — 게이트 1(원거리)이 최상인데 게이트 0에서 떨어지는 니치가 실제로 나온다(2절 러닝).

### 세 게이트의 순서

```
게이트 0 · 원본이 존재하는가          →  없으면 즉시 탈락
      ↓
게이트 1 · 원거리 추적에 가치가 있는가  →  없으면 "잘라주는 앱"이 된다
      ↓
게이트 2 · 제품 정의가 성립하는가      →  추적 대상이 본인인가 · 기록이 공개보다 먼저인가
```

### 4-1. 🟢 N3가 게이트 2에서 가장 강한 이유 — 남의 아이가 찍히기 때문이다

학예회·운동회 영상에는 **다른 집 아이들이 대량으로 찍힌다.** 보통은 이것이 결함이다. 부모들이 SNS에 못 올리는 이유가 바로 그거다.

**HILiT에서는 결함이 아니다.**

| | 공개 전제 편집앱 (CapCut 등) | **HILiT** |
| --- | --- | --- |
| 기본 공개 범위 | 공개 발행이 목적 | 🔴 **`private` · DB `DEFAULT`로 강제** (ADR-4) |
| 남의 아이가 찍힌 영상 | 🔴 **올릴 수 없다 → 제품이 쓸모없다** | 🟢 **안 올려도 남는다 → 제품이 그대로 작동한다** |
| 법무 게이트 | 공개 시 `FACE_CONSENT`·`MINOR_SUBJECT` | 🟢 **비공개 기록은 두 게이트의 차단 대상이 아니다** |

> 🔴 **CLAUDE.md 절대 규칙 1(D4)이 N3에서 경쟁 우위로 바뀐다.**
> *"공개 여부와 무관하게 개인 기록으로 남긴다"* 는 설계는, **남의 아이 때문에 공개가 불가능한 시장에서 유일하게 작동하는 설계다.**
>
> 🔺 단, 법무 게이트가 사라지는 게 아니다 — **공개 발행·그룹 공개 경로는 여전히 `FACE_CONSENT`·`MINOR_SUBJECT` 승인 전까지 차단**이며, `MINOR_POLICY`는 가입 플로우 전체를 막는다. N3는 **비공개 경로에서만** 게이트 2를 통과한다.

### 4-2. 🚫 N5 아이돌 팬 탈락 — 게이트 1이 최상인데도

## 6. 🔴 이번 판정의 핵심 발견

### 6-1. 게이트는 니치에 걸리지 않는다. 촬영 상황에 걸린다

5개 니치 중 **통째로 통과하거나 통째로 탈락한 것은 하나도 없다.**

```
N2 레저    →  서핑·스노보드 통과 / 러닝·클라이밍·등산·헬스 탈락
N3 일상    →  학예회·운동회 통과(최상) / 실내 가족 행사 탈락
N4 여행    →  전부 탈락, 단 액티비티는 N2로 재분류하면 통과
```

> 🔴 **따라서 니치를 그대로 세그먼트로 쓰면 안 된다.**
> 니치는 **마케팅 진입 언어**로 쓰고, **제품이 작동하는 단위는 "원거리 촬영이 강제되는 상황"** 으로 잡아야 한다.
>
> 이것을 무시하면 *"여행 영상도 됩니다"* 라고 광고하고 셀피를 받게 된다. 셀피에서 HILiT는 CapCut의 열화판이다.

### 6-2. 통과한 3개가 같은 기술 문제로 수렴한다

| 상황 | 기술 조건 |
| --- | --- |
| 농구 코트 반대편에서 5명 중 나 | 원거리 · 다인 · 유사 복장 |
| 학예회 객석에서 20명 중 내 아이 | 원거리 · 다인 · **단체복** |
| 해변에서 여러 서퍼 중 나 | 원거리 · 다인 · **유사 슈트** |

> 🟢 **부록B 설계 원칙 01(종목 중립 신호)이 이미 요구한 것이 그대로 통한다.** 세 상황 모두 *"온전히 잡힌 구간 + 대상 지속성"* 이라는 같은 신호를 쓴다. **확장 비용이 예상보다 낮다.**

### 6-3. N3의 B2B 경로가 N1과 같은 곳으로 수렴한다

부록D가 확인한 **체육교습업 2,651개소(2023, +28.8%)** `[SOURCE]` 는 유소년 스포츠 교습 사업체다. 이들이 여는 것이 곧 **유소년 경기·발표회**다.

> 🔴 **N3는 새 시장이 아니라 N1의 B2B 경로를 정면에서 다시 만난 것이다.**
> 확장이 아니라 **심화**로 취급해야 한다. 새 데이터셋·새 마케팅 채널이 필요 없다는 뜻이고, 되돌림 비용이 5개 니치 중 가장 싸다.
