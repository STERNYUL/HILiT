## 2. 🔴 정정 — 190만원은 하드웨어 인공물이 아니다

`04` 2-3절에서 *"190만원에 하드웨어가 섞여 HILiT가 복제 못 한다"* 고 의심했다. **기각한다.**

| 근거 | 내용 |
| --- | --- |
| **1** | **ARR은 정의상 반복 매출**이다. 일회성 하드웨어 판매는 ARR에 들어가지 않는다 |
| **2** | $1,488은 구독 구간 **$804~$1,308+ 바로 위**에 있다. 애드온(Veo Live·Analytics 2)이 그 차이를 설명한다 |
| **3** | 🔴 **결정적** — 실제 클럽이 사는 것은 **Club 티어(무제한·10팀·300사용자)** 이고, 이는 최저가 $67이 아니라 **$109+ 구간**이다 |

> ### 🔴 제 앞선 예측이 틀렸다
> 저는 *"클럽당이 190만원 → 104만원으로 내려가 필요 클럽이 두 배가 된다"* 고 했다. **104만원($67/월)은 Starter 티어**(10시간·1팀·15사용자)이고, **클럽이 살 수 있는 상품이 아니다.** 티어를 잘못 골라 계산한 것이다.
>
> **클럽 티어 기준 연 $1,308+ ≈ 170만 원**이고, 애드온을 더하면 **190만원은 무리한 값이 아니다.** 04 4차검증의 숫자는 대체로 유효하다.

## 3. 손익분기 재계산

```
손익분기 연매출 = 약 6 ~ 12억 원   (TAM 6절 · 04 4차검증 4절)
필요 클럽 수    = 손익분기 ÷ 클럽당 연 매출
```

| 클럽당 연 매출 | 근거 | 필요 클럽 수 | 판정 |
| ---: | --- | ---: | :---: |
| **242만 원** ($1,860) | ARR $37.2M ÷ **20,000 클럽** (공식 자료) | **248 ~ 496곳** | 🟢 가장 유리 |
| **190만 원** ($1,488) | ARR ÷ **25,000** — 04 4차검증 채택값 | **316 ~ 632곳** | ✅ 저장소 현행 |
| **170만 원** ($1,308) | Veo **Club 티어 구독만** (애드온 제외) | **353 ~ 706곳** | 🟡 보수적 |
| **104만 원** ($804) | Veo **Starter** 티어 — 🔴 클럽에 부적합 | **577 ~ 1,154곳** | 🔴 참고용 |

> ### 🔴 결론 — 필요 클럽 수는 확정할 수 없다. 스프레드가 4.6배다
> **248곳 ~ 1,154곳.** 04 4차검증의 320~630곳은 이 구간의 중간이며 **틀린 값은 아니지만 정밀하지도 않다.**
>
> 🟢 **현실적 채택 구간은 170~242만 원 → 필요 클럽 약 250~700곳**이다. Starter 티어(104만 원)는 클럽 상품이 아니므로 제외한다.

### 3-1. 🔴 이것을 체육교습업 모집단에 대입하면

`04` 1절에서 확인한 분모(법정 8종목 · 2,651개소 · 2023)에 대입한다. `[예시계산]`

| 진입 범위 | 클럽 수 | 필요 250곳 | 필요 700곳 |
| --- | ---: | :---: | :---: |
| **농구 단독** (8종목 균등 배분 가정) | **331곳** | 🟡 침투율 **76%** | 🔴 **불가능** |
| **게이트 1 명확 통과 4종**(농구·축구·야구·빙상) | **1,326곳** | 🟢 침투율 **19%** | 🟢 침투율 **53%** |
| 체육교습업 전체 8종목 | 2,651곳 | 🟢 9% | 🟢 26% |

> ### 🟢 이번 재계산이 N3 권고를 숫자로 뒷받침한다
> **농구 단독 클럽으로는 손익분기가 위태롭다** — 필요 클럽이 구간 하단(250곳)이어도 침투율 76%가 필요하고, 상단(700곳)이면 모집단 자체가 부족하다.
>
> 🔴 **게이트 1 통과 4종으로 넓히면 침투율이 19~53%로 떨어진다.** `01` 7-1절이 N3(학예회·운동회·유소년 경기)를 확장 3순위로 권고한 근거가, 이제 **정성 판단이 아니라 산술**이 됐다.
>
> 🔺 **다만 침투율 19~53%도 쉬운 숫자가 아니다.** 그리고 `04` 1-3절의 `MINOR_POLICY`가 승인되지 않으면 **이 경로의 매출은 0**이다.

## 4. 🔴 구조적 발견 — Veo는 장비를 팔고, HILiT는 장비 없이 들어간다

의심 2번은 기각됐지만, 요금 구조를 보다가 **더 중요한 것**이 나왔다.

**Veo가 클럽에서 돈을 받는 이유는 촬영 자동화다.** 무인 카메라를 설치하면 경기가 알아서 녹화된다. 그런데 **HILiT는 촬영을 하지 않는다**(A-T2) — 게이트 0이 *"원본이 이미 있다"* 를 요구한다.

### 4-1. 클럽에 원본이 이미 있는 경로는 셋뿐이다

| 경로 | 상태 | HILiT의 자리 |
| --- | --- | --- |
| **① Veo류 장비를 이미 도입** | 팀 하이라이트를 이미 받고 있다 | 🟡 **애드온 경쟁** — 개인별 15초는 Veo가 안 준다 |
| **② 코치·학부모가 스마트폰으로 찍는다** | 원본은 있으나 품질·일관성이 낮다 | 🟢 **여기가 진짜 자리** |
| ③ 안 찍는다 | 원본 없음 | 🚫 게이트 0 탈락 |

> 🔴 **②가 HILiT의 클럽 B2B 타깃이다 — 즉 "Veo를 못 산 클럽"이다.**

### 4-2. 🟢 그리고 그것이 진입 우위다

| | **Veo** | **HILiT** |
| --- | ---: | ---: |
| 하드웨어 | **199 ~ 260만 원** (일회성) | 🟢 **0원** |
| 구독 (연) | 170 ~ 190만 원 | 190만 원 (가정) |
| **1년차 총액** | **약 350 ~ 450만 원** | 🟢 **약 190만 원** |

부록D가 확인한 유소년 클럽 경제(원생 40명 × 월 15만 원 ≈ 연 7,200만 원)에 대입하면:

| | 1년차 부담률 |
| --- | ---: |
| **Veo** (하드웨어 포함) | **4.9 ~ 6.3%** |
| **HILiT** (하드웨어 없음) | 🟢 **2.6%** |

> 🔺 **부록D 2-2절의 "Veo 수준(연 190만원) 부담률 = 매출의 2.6%"는 구독만 본 값이다.** 하드웨어를 포함한 1년차 실부담은 **4.9~6.3%** 이며, **HILiT의 2.6%가 Veo의 절반 이하**다.
>
> 🟢 **"장비를 팔지 않는다"가 약점이 아니라 진입 장벽 우위다.** A-T2(앱이 촬영하지 않는다)라는 기술 제약이 여기서 가격 우위로 바뀐다.

### 4-3. 🔴 대가 — Gate A가 스마트폰 원본으로 판정돼야 한다

경로 ②를 타면 입력이 **삼각대에 올린 스마트폰 원본**이다. Veo의 듀얼 4K 180° 파노라마가 아니다.

| | Veo 원본 | **HILiT가 받는 원본** |
| --- | --- | --- |
| 해상도·화각 | 듀얼 4K · 180° 파노라마 | 스마트폰 단일 렌즈 |
| 고정 | 전용 마운트 | 🔺 **삼각대 또는 손** |
| 일관성 | 무인 자동 | 🔴 **촬영자에 따라 편차** |

> 🔴 **따라서 Gate A(제외 후 탐지율 ≥ 85%)의 평가 데이터셋은 스마트폰 원본이어야 한다.**
> 전용 카메라 영상으로 85%를 넘겨도, 실제 입력이 스마트폰이면 그 값은 판정 근거가 아니다.
>
> 🟢 **PRD §8-2 E1이 이미 "농구 원본 n=100편(40분급)"으로 잡아둔 것과 충돌하지 않는다** — 촬영 기기 조건을 명시하면 된다. 🔺 **다만 현재 명시가 없다.**
