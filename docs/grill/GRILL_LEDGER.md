## 토픽별 충돌 근거

### 🔴 T1 — AI 선제안 vs REQ-FUNC-005

**새 결정**: *AI 러닝 → 결과물 제시 → 고객 확인*

| 기존 | 충돌 |
| --- | --- |
| **REQ-FUNC-005** | *"제시된 후보 **100% 전부**에 선택·제외가 가능해야 한다"* — **후보 목록의 존재를 전제한다** |
| **§12 3단계** | 하이라이트 선택 화면. 진입 조건 `selection_confirmed` |
| **차별점 D2** | 4/6 커버리지 · 모방 난이도 낮음이나 **정체성** |

🔺 **다만 D2의 해석은 새 안과 모순되지 않을 수 있다.** SRS §4.2 주석: *"최종 선택권이 사람에게 있다는 것은 **사람이 고르기 쉬운 상태까지 만들어 준다**는 뜻이지, 판단하기 어려운 것을 떠넘긴다는 뜻이 아니다."* **AI 선제안은 그 해석의 극단이다.** 쟁점은 *"확인이 선택인가"* 다.

### 🔴 T2 — 수작업 고도화 vs 편집 이탈

**새 결정**: *"더 좋은 결과물을 원하십니까?" → 수작업 고도화*

| 기존 | 충돌 |
| --- | --- |
| **§3 여정 ④** | 편집 = **2차 이탈**(30분 초과 시 포기) |
| **UX-002 항목 14** | *"원본 자르기·회전, 후보 구간 직접 조정, 수동 구도 조정은 요구사항에 없다. 넣는 순간 30분 이탈 지점을 되살린다"* |
| **§3 결론** | 🔴 *"한 번이라도 편집에서 지치면 다음 주에 삼각대를 아예 안 들고 간다"* |

### 🔴 T3 — 결과물 길이가 정의되어 있지 않다

| 출처 | 값 | 성격 |
| --- | --- | --- |
| REQ-FUNC-007 | **15초** | 🔺 **음악이 맞춰지는 길이**일 뿐 |
| REQ-NF-004 | 15초 | 렌더 측정 기준 |
| DS §4.2 `GeneratedVideo` | **≤ 60초** | 🔺 **DB 상한**일 뿐 |
| FR-014 | `[TBD]` | *"선택 상한 미정 — 30개 전부 선택하면 15초를 크게 넘는다"* |

🔴 **완성 영상의 목표 길이를 정한 요구사항이 없다.**

### 🔴 T4 — 편집 중 피드 시청 vs 클라이언트 렌더

**새 결정**: *편집이 되는 동안 숏폼을 보게끔*

| 기존 | 충돌 |
| --- | --- |
| **v2.2 §3.3** | 렌더를 **사용자 단말**에서 수행 (원가 0원의 근거) |
| **REQ-NF-004** | 🔺 단말 등급별 p95 재정의 필요 |
| **REQ-FUNC-011** | 피드는 영상 자동재생 |

🔴 **렌더와 피드 재생이 같은 단말에서 동시에 돈다.** 자원 경합으로 렌더가 느려지고, 하한 등급에서는 완성 실패가 늘 수 있다.

### T5 — CC0 확정의 파급

| 기존 | 영향 |
| --- | --- |
| REQ-FUNC-007 | **5갈래 500곡**(감성 120 · 여행 80 · 일상 110 · 운동 105 · 추억 85) |
| NF-016 §조달 경로 | 🔺 *"CC0는 카탈로그가 좁다 — 5갈래 중 **운동·일상 확보가 어렵다**"* |

### T6 — 캡컷 대비 속도 목표

| 기존 | 상태 |
| --- | --- |
| REQ-NF-003 | 탐지 p95 ≤ 8분 `[PROPOSED]` |
| REQ-NF-004 | 렌더 p95 ≤ 90초 `[PROPOSED]` · 단말 종속 |

🔴 **경쟁 제품 대비 목표가 요구사항 어디에도 없다.** 두 값은 내부 상한이지 경쟁 기준이 아니다.

### 🔴 T13 — 편집 유료 잠금 vs 제품 정의·검증 체계 `RESOLVED → SRS ADR-8`

**질문**: freemium에서 **편집툴을 부분적으로 유료**로 할 수 있는가. PRD `ADR-01`(*"편집으로 과금하지 않는다"* · 확정)의 사정거리가 문면으로 갈리지 않았다.

| 기존 | 충돌 |
| --- | --- |
| **REF-03 ADR-01** | *"편집으로 과금하지 않는다"* `확정` — **기능 잠금 금지인지 과금 축 전면 금지인지 불명** |
| **REQ-NF-013** | *"편당 처리 원가 상한 확정 전 무제한 업로드를 열지 않는다"* — **쿼터의 존재를 이미 요구한다** |
| **REQ-FUNC-003 · Gate A** | 탐지율 ≥ 85% **단일 판정선** — 🔴 품질 등급화 시 판정 대상이 사라진다 |
| **REQ-FUNC-027** | *"확신이 없으면 보여주지 않는다"* — 🔴 `τ` 등급별 차등은 이 규칙을 요금제에 종속시킨다 |
| **REQ-FUNC-005 · ADR-6 · D2** | `[직접 고르기]` 병존 — 🔴 접근을 유료로 가두면 D2가 이름만 남는다 |
| **§2.4 ④ 편집 이탈** | 수작업 도구는 요구사항에 없다(UX-002 14) — 유료로 붙이면 **가장 비싼 코호트에게 이탈 지점을 판다** |
| **REF-03 R3** | D1 복제 대비 방어선 = REQ-FUNC-023(선택 데이터) · 결론이 *"속도가 방어다"* — 🔴 **기능 잠금이 방어선 자체를 없앤다** |

🔴 **판정의 무게는 매출이 아니라 두 곳에 있었다** — ① Gate A·B가 어느 등급으로 판정되는가 ② 사용자 수가 줄면 REQ-FUNC-023이 시작되는가. 3축(분량·재작업·규격)은 둘 다 건드리지 않는 유일한 조합이다.
