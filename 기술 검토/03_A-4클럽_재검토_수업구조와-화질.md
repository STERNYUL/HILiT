# 1. 🔴 먼저 — 페르소나 설정에 오류가 있었습니다

## 1-1. 무엇을 잘못 세웠나

제가 A-4를 이렇게 설정했습니다.

> *"수업 전체를 한 대의 카메라로 찍는다. **40명이 한 영상에 섞여 있다.**"*
> *"아이별로 자르면 **40명 × 3분 = 하루 2시간.**"*

**이건 "등록 원생 40명"을 "한 타임 40명"으로 잘못 옮긴 것입니다.**

## 1-2. 실제 운영 구조

국내 유소년 농구 클럽은 **연령·수준별로 반을 나눠** 운영합니다.

| 확인 사항 | 내용 | 출처 |
| --- | --- | --- |
| 반 편성 | **초등 저학년 / 초등 고학년 / 중등 / 고등**으로 분리 | [KBL 유소년](https://youth.kbl.or.kr/) · [주니어 나이츠](https://www.sksports.net/Knights/juniorknight/jn_introduce.asp) |
| 수업 시간 | **60~80분** | [퀀텀 유소년 농구](https://www.quantumbball.com/youth) |
| 수준 조절 | *"코치님들이 학생들 수준에 따라 조절"* | 퀀텀 |
| 정원·수강료 | 🔴 **비공개** — *"수업 인원, 시간, 횟수는 협의 가능"* | 퀀텀 · [링크농구교실](https://www.link-basketball.com/) |

> ### 📌 정정
> **등록 원생 40명 ≠ 한 타임 40명.**
> 주 5일 수업 × 하루 2~3타임이면 **한 타임 실제 인원은 8~15명**이 현실적입니다. 40명은 **클럽의 총 회원 수**입니다.

## 1-3. 이 정정이 바꾸는 것

| 항목 | 기존 설정 | **정정** |
| --- | --- | --- |
| 한 영상의 인원 | 40명 | **8~15명** |
| 편집 부담 | 40명 × 3분 = 2시간 | **12명 × 3분 = 36분** |
| 코트 사용 | 풀코트 추정 | **하프코트 가능성 높음** (인원이 적으므로) |
| 촬영 거리 | 10~25m | 🟢 **5~14m** |

# 3. A-4 페르소나 수정안

## 3-1. 수정 항목

| 항목 | 기존 | **수정** |
| --- | --- | --- |
| 한 타임 인원 | 40명 | **8~15명** (등록 40명은 총 회원) |
| 편집 부담 | 하루 2시간 | **타임당 30~40분 × 하루 2~3타임** |
| 촬영 거리 | 10~25m | **5~14m** (드릴 구간 5~8m) |
| 화질 판정 | 🔴 대부분 불가 | 🟢 **드릴 구간 유효** |
| 촬영 통제력 | 없음 | 🟢 **높음 — 코치가 정한다** |

## 3-2. Pain의 크기는 그대로입니다

인원이 40 → 12로 줄어도 **Pain은 작아지지 않습니다.**

```
기존 가정:  40명 × 3분 = 하루 2시간   → 안 함
수정:      12명 × 3분 = 36분/타임
           × 하루 2~3타임 = 72~108분  → 여전히 안 함
```

> **총량은 비슷합니다.** 한 타임에 40명이 아니라 여러 타임에 나뉘어 있을 뿐이고, 코치는 **타임 사이 10분**에 처리해야 하므로 오히려 **한 번에 쓸 수 있는 시간이 더 짧습니다.**
>
> **P-10(다인 분배)의 AOS는 유지됩니다.**

## 3-3. 그런데 Pain의 성격이 바뀝니다

| | 기존 이해 | **수정된 이해** |
| --- | --- | --- |
| 문제 | *"40명을 한 번에 못 나눈다"* | *"타임마다 12명씩, 하루 3번 반복해야 한다"* |
| 필요한 것 | 대량 일괄 처리 | 🟢 **빠른 반복 처리 + 타임별 관리** |
| 설계 함의 | 배치 업로드 | **타임(클래스) 단위 그룹 관리** |

> **"원생 40명 목록"이 아니라 "오늘 3교시, 초등 고학년반 12명"** 이 처리 단위입니다. 이게 UI 설계를 바꿉니다.

# 4. 촬영 가이드 — 클럽용 재작성

앞 문서 4-1절에서 「가」안(반 코트 촬영)을 권고했는데, **이미 그렇게 하고 있을 가능성이 높습니다.** 가이드가 훨씬 가벼워집니다.

## 4-1. 클럽 대상 가이드 (3줄)

```
📍  드릴하는 골대 쪽 엔드라인 근처에 세워주세요
    골밑에서 5m 안쪽이면 아이들이 크게 담겨요

📱  세로로 세우면 한 명씩 뽑을 때 훨씬 선명해요

🔁  매 수업 같은 자리에 두시면 결과가 일정해집니다
```

## 4-2. 🔴 세로 촬영의 트레이드오프 — 클럽에서는 다릅니다

| 거리 | 세로 촬영 시 담기는 폭 | 코트 폭 대비 |
| ---: | ---: | ---: |
| 5m | 4.2m | 28% |
| 8m | 6.8m | 45% |
| 10m | 8.4m | 56% |
| 14m | 11.8m | 79% |

> **개인 경기에서는 폭이 좁아 문제였지만, 클럽 드릴은 다릅니다.**
> 슛·레이업·드리블 드릴은 **골대 앞 좁은 구역**에서 이뤄지므로, 5~8m 거리에서 담기는 4~7m 폭이면 대개 충분합니다.
>
> ⚠️ 다만 **5:5 스크리미지(연습 경기)** 를 할 때는 풀코트가 필요해 개인 사용자와 같은 제약을 받습니다. **드릴은 세로, 경기는 가로**로 안내해야 합니다.

## 6-1. B2B 우선 근거가 강해집니다

| 근거 | 기존 | **추가** |
| --- | --- | --- |
| 매출 | 클럽당 연 190만원 (Veo 실측) · 손익분기 320~630곳 | — |
| 시장 | 체육교습업 2,651개소 · **연 +28.8%** | — |
| 🟢 **기술** | — | **촬영 조건 통제 가능 · 거리 5~8m · 실내 조명** |

> **개인 시장은 촬영 조건을 통제할 수 없어 성능 편차가 큽니다.** D-1(야간 공원 코트)이 그 극단입니다.
> **클럽은 코치가 카메라를 놓는 위치를 정합니다.** 같은 기술로 더 나은 결과가 나옵니다.
>
> **"B2B 먼저"가 매출 이유뿐 아니라 기술 검증 이유로도 옳습니다.** 통제된 조건에서 정확도를 완성한 뒤 개인 시장으로 내려가는 순서가 자연스럽습니다.

## 6-2. Trace와의 비교가 달라집니다

| | Trace (축구) | **HILiT (클럽 농구)** |
| --- | --- | --- |
| 필드 크기 | 축구장 **105×68m** | 하프코트 **14×15m** |
| 촬영 거리 | 수십 m | **5~8m** |
| 하드웨어 | 🔴 **필수** (거리 때문에) | 🟢 **불필요** |

> ### 🟢 여기서 Trace가 하드웨어를 쓰는 이유가 드러납니다
> **축구장은 105m입니다.** 그 거리에서 선수를 4X 줌으로 잡으려면 듀얼렌즈 고해상도가 필요합니다.
>
> **농구 하프코트는 14m입니다.** 휴대폰 4K로 충분합니다.
>
> **"종목이 다르다"가 단순한 차별점이 아니라, 하드웨어 없이 가능한 이유였습니다.** 이건 D3 논리를 강화합니다 — *"우리는 하드웨어를 안 쓰는 게 아니라, 안 써도 되는 종목을 골랐다."*
