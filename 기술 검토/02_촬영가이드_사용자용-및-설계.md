# 0. 이 가이드가 필요한 이유 — 한 장 요약

| 조건 | 결과 |
| --- | --- |
| 1080p로 찍음 | 🔴 **확대 여유 0배** — 제품이 작동하지 않음 |
| 4K 가로로 찍음 | 확대 여유 **1.125배** |
| **4K 세로로 찍음** | 🟢 확대 여유 **2.0배** |
| 15m 밖에서 찍음 | 인물이 화면의 **15%** — 목표까지 4.1배 필요 |

> **촬영 단계에서 결정되는 것이 편집 단계에서 복구되지 않습니다.** 그래서 가이드가 기능만큼 중요합니다.

# 1. 🔴 설계 원칙 4가지

| # | 원칙 | 이유 |
| --- | --- | --- |
| **01** | **가르치려 들지 않는다** | 사용자는 촬영 강의를 들으러 온 게 아니다. 앱을 켠 시점은 이미 **경기가 끝난 뒤**다 |
| **02** | **첫 세션에서는 아무것도 요구하지 않는다** | N2(리터러시 장벽) 카드의 결론. 온보딩 결정 횟수가 곧 이탈률이다 |
| **03** | **실패한 뒤에 가르친다** | D-1 강민석 카드 — *"오류가 발생했습니다"* ❌ → *"빛이 부족해 놓쳤어요. 다음엔 이렇게"* ⭕ |
| **04** | **숫자를 그대로 말하지 않는다** | *"5.8m 이내"* ❌ → *"사이드라인 근처"* ⭕. 사용자는 미터로 세상을 보지 않는다 |

# 2. 사용자에게 보여줄 문구

## 2-1. 🟢 기본 가이드 — 3줄

앱 내 「촬영 팁」 화면에 들어갈 최종 문구입니다.

```
📱  세로로 세워서 찍어주세요
    화면을 세로로 두면 나중에 훨씬 크게 담을 수 있어요

📐  코트 전체보다 내가 뛰는 쪽을 담아주세요
    멀리 있으면 편집해도 작게 나와요

⚙️  화질은 4K로 설정해주세요
    설정 › 카메라 › 비디오 촬영 › 4K
```

> **세 줄 이상 쓰지 않습니다.** 순서는 효과 크기 순입니다 — 세로 전환이 78% 개선, 거리가 그다음, 4K는 안 하면 아예 작동하지 않는 최소 요건입니다.

## 2-2. 상황별 한 줄 (필요할 때만 노출)

| 상황 | 문구 |
| --- | --- |
| 삼각대 있음 | *"사이드라인 근처, 내가 주로 뛰는 쪽에 세워주세요"* |
| 삼각대 없음 | *"가방이나 벤치에 기대 세워도 괜찮아요. 화면이 기울지 않게만"* |
| 야간·실외 | *"어두우면 사람을 놓칠 수 있어요. 조명이 있는 쪽을 등지고 세워주세요"* |
| 여러 명 촬영 | *"모두를 담으려면 멀어지고, 멀면 각자가 작게 나와요. 반 코트씩 나눠 찍는 것이 나아요"* |
| 안드로이드 | *"8K로 찍을 수 있다면 8K가 가장 좋아요"* |

## 2-3. 🔴 실패 후 안내 — 가장 중요한 문구

**결과가 안 나왔을 때 이 화면이 뜹니다.** D-1 강민석이 *"제가 잘못 찍은 거겠죠"* 라며 조용히 앱을 지우는 것을 막는 장치입니다.

| 실패 원인 | ❌ 쓰지 말 것 | ⭕ 이렇게 |
| --- | --- | --- |
| 저조도 | "처리에 실패했습니다" | **"빛이 부족해서 중간중간 놓쳤어요.**<br>다음엔 조명이 있는 쪽을 등지고 세워보세요" |
| 거리 과다 | "화질이 낮습니다" | **"조금 멀리서 찍히셨네요.**<br>다음엔 사이드라인 가까이 세우면 훨씬 크게 담을 수 있어요" |
| 유사 복장 | "인식 실패" | **"비슷한 옷을 입은 분들이 많아 헷갈렸어요.**<br>혹시 다른 색 상의가 있으면 다음에 입어보세요" |
| 해상도 부족 | "지원하지 않는 형식" | **"영상 화질이 조금 아쉬워요.**<br>설정 › 카메라에서 4K로 바꾸면 결과가 달라져요" |
| 프레임 이탈 | "추적 불가" | **"화면 밖으로 자주 나가셨어요.**<br>다음엔 조금 더 뒤에서 넓게 찍어보세요" |

> **문장 구조를 고정합니다.**
> `[무엇이 일어났는지] + [다음엔 어떻게]`
> 사과하지 않고, 사용자를 탓하지 않고, **행동 하나만** 제시합니다.

# 3. 언제 보여주는가 — 노출 설계

## 3-1. 노출 지점 4곳

| 시점 | 무엇을 | 강도 | 근거 |
| --- | --- | :---: | --- |
| **① 온보딩** | 🔴 **아무것도 안 보여줌** | — | N2 카드 — 첫 세션 결정 0회 원칙 |
| **② 첫 결과 직후** | 성공했으면 → 아무것도. 아쉬우면 → 실패 안내 1줄 | 낮음 | 성공 경험을 먼저 |
| **③ 실패 시** | 실패 원인별 문구 (2-3절) | **높음** | D-1 이탈 방지 |
| **④ 두 번째 업로드 전** | 기본 가이드 3줄 (2-1절) | 중간 | 이미 한 번 써봤으니 맥락이 있음 |

> ## 🔴 ①이 핵심입니다
> **온보딩에서 촬영법을 가르치면 안 됩니다.** 사용자는 이미 찍어둔 영상을 들고 왔고, 지금 필요한 건 결과물이지 다음 촬영 준비가 아닙니다.
>
> *"이미 찍어둔 영상으로 오늘 시작할 수 있다"* 가 하일릿의 실제 우위인데, 온보딩에서 촬영 가이드를 보여주면 **그 우위를 스스로 부정하는 셈**입니다.

## 3-2. 사전 판정과의 연결

Value Chain의 「사전 판정」 단계(GPU 투입 전 필터)가 이 가이드와 짝을 이룹니다.

```
업로드
  ↓
사전 판정 ─── 통과 ──→ 처리 → 결과
  │
  └─ 거부 ──→ 🔴 이유 + 다음 행동 (2-3절 문구)
              "처리 실패"만 띄우면 안 됨
```

| 사전 판정 항목 | 임계값 (초안) | 거부 시 문구 |
| --- | --- | --- |
| 해상도 | 세로 1080px 미만 | 해상도 부족 |
| 평균 밝기 | ⚠️ 미정 | 저조도 |
| 흔들림 | ⚠️ 미정 | (거부하지 않고 경고만) |
| 길이 | 10초 미만 / 3시간 초과 | 별도 |

> ⚠️ **임계값이 너무 엄격하면 D-1의 정상 영상까지 거부합니다.** 사전 판정은 **거부보다 경고를 기본**으로 하고, 확실히 처리 불가인 경우만 막습니다.

# 4. 페르소나별 가이드

| 페르소나 | 촬영 조건 | 우선 안내 | 예상 결과 |
| --- | --- | --- | :---: |
| **A-1 김도현**<br>코트 옆 삼각대 | 7~16m | **세로 전환** + 내가 뛰는 쪽 | 🟡 같은 쪽 유효, 반대편 제한 |
| **A-2 박서연**<br>사이드라인 촬영담당 | 5~15m | 반 코트씩 나눠 찍기 | 🟡 조건부 |
| **D-1 강민석**<br>벤치 거치·야간 | 10~20m | **조명 방향** + 기울기 | 🔴 실패 안내가 핵심 |
| **A-4 서지훈**<br>체육관 고정·40명 | 10~25m | 🔴 **별도 대응 필요** (아래) | 🔴 대부분 원거리 |

## 4-1. 🔴 A-4(클럽)만 다른 답이 필요합니다

원생 40명이 코트 전체에 흩어져 있어 **대부분 15m 이상**입니다. 개인용 가이드로는 해결되지 않습니다.

| 선택지 | 내용 | 대가 |
| --- | --- | --- |
| **가** | 반 코트씩 나눠 촬영 (수업을 반으로 나눔) | 코치의 운영 방식을 바꿔야 함 |
| **나** | 두 대로 양쪽에서 촬영 | 기기 2대 필요 |
| **다** | 🔴 **광각 액션캠 권장** | *"하드웨어 없이"* 차별점이 B2B에서 흔들림 |
| **라** | 클럽에는 **낮은 확대율**로 결과물 제공 | 품질 기대치를 낮춰야 함 |

> **권고는 「가」입니다.** 코치가 이미 조를 나눠 수업하는 경우가 많고, 하드웨어를 요구하지 않으며, **결과물 품질이 개인 사용자와 같아집니다.**
> 다만 이건 **가정이므로 A-4 인터뷰에서 확인해야 합니다** — *"수업을 반 코트씩 나눠 진행하시나요?"* 를 문항에 추가할 것을 권고합니다.

# 5. 온보딩 체크리스트 (개발용)

```
[ ] 온보딩에서 촬영 가이드를 노출하지 않는다
[ ] 첫 업로드는 이미 찍어둔 영상으로 가능하다
[ ] 사전 판정 거부 시 원인 + 다음 행동을 함께 보여준다
[ ] 실패 문구에 "실패", "오류", "불가"라는 단어를 쓰지 않는다
[ ] 실패 건에는 과금하지 않는다
[ ] 가이드에 미터·픽셀 같은 단위를 노출하지 않는다
[ ] 4K 설정 안내에 기기별 실제 경로를 넣는다 (iOS/Android 분기)
[ ] 두 번째 업로드 전에만 기본 가이드 3줄을 노출한다
```

# 7. 요약

> **가이드의 목표는 사용자를 좋은 촬영자로 만드는 것이 아닙니다.** 이미 찍어둔 영상으로 첫 성공을 만들고, **실패했을 때 다음을 알려주는 것**입니다.
>
> 그래서 순서가 이렇습니다 — **온보딩에서는 침묵, 실패 후에 안내, 두 번째부터 가이드.**

| 우선순위 | 항목 | 효과 |
| :---: | --- | --- |
| **1** | 실패 후 안내 문구 | D-1 이탈 방지 — 재시도율 최저층 |
| **2** | 세로 촬영 안내 | 확대 여유 **78% 개선**, 코드 변경 없음 |
| **3** | 4K 설정 안내 | 1080p면 제품이 아예 작동 안 함 |
| **4** | 거리 안내 | 15m 밖은 결과 보장 불가 |
| **5** | A-4 클럽 별도안 | 매출 경로 · 인터뷰로 확정 |
