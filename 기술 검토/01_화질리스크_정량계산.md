# 1. 계산 전제

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 카메라 | iPhone 15 Pro 메인 · **24mm 환산** | [Apple 기술사양](https://support.apple.com/en-us/111829) · [GSMArena](https://www.gsmarena.com/apple_iphone_15_pro-review-2620p5.php) |
| 화각 | 수평 **73.7°** · 16:9 동영상 수직 **45.7°** | 24mm 환산에서 산출 |
| 원본 | 4K **3840 × 2160** | 동일 |
| 출력 | 세로 숏폼 **1080 × 1920** | 인스타 릴스·틱톡 규격 |
| 인물 | 신장 **1.75m** | 성인 남성 평균 |
| 코트 | FIBA 규격 **28m × 15m** | 국제농구연맹 |

**핵심 공식**

```
거리 d에서 화면에 담기는 높이 H = 2 × d × tan(수직화각/2)
인물이 차지하는 픽셀 = 세로해상도 × (1.75 / H)
```

# 2. 🔴 가장 중요한 발견 — 최대 크롭 배율

**세로 숏폼(1080×1920)을 뽑을 때 화질 손실 없이 확대할 수 있는 배율**입니다.

| 촬영 방식 | 원본 | 계산 | **최대 배율** |
| --- | --- | --- | :---: |
| **가로 4K** | 3840×2160 | 세로 2160 ÷ 1920 | 🔴 **1.125배** |
| **세로 4K** | 2160×3840 | min(2160÷1080, 3840÷1920) | 🟢 **2.0배** |
| 가로 8K | 7680×4320 | 4320 ÷ 1920 | 2.25배 |
| **Trace PlayerCam** | 듀얼렌즈 전용기 | 공식 사양 | **4.0배** |

> ## 🔴 가로로 찍으면 확대 여유가 12.5%뿐입니다
>
> 세로 숏폼의 높이 1920px를 채우려면 원본 세로 2160px 중 **89%를 그대로 써야** 합니다. 남는 여유가 271px뿐이라, **"코트 구석의 나를 화면 중앙에 크게"** 는 물리적으로 불가능합니다.
>
> **Trace와 3.6배 차이**입니다. 이건 알고리즘으로 못 메웁니다.

# 4. 농구 코트 실측 대입

## 4-1. 실제 촬영 위치별 거리

FIBA 코트(28×15m) 기준, **사이드라인 중앙에 삼각대**를 세웠을 때 피사체까지의 거리입니다.

| 피사체 위치 | 거리 | 인물 픽셀 | 화면 대비 | 판정 |
| --- | ---: | ---: | ---: | :---: |
| 같은 쪽 3점 라인 | 약 **7m** | 640px | 33.3% | 🟡 |
| 코트 중앙 | 약 **7.5m** | 597px | 31.1% | 🟡 |
| **반대편 3점 라인** | 약 **14m** | 320px | 16.7% | 🔴 |
| **반대편 골밑** | 약 **16m** | 280px | 14.6% | 🔴 |
| 대각선 반대 코너 | 약 **19m** | 236px | 12.3% | 🔴 |

> 🔴 **김도현 페르소나의 페인포인트가 수치로 확인됩니다** — *"코트 반대편에 있는 나는 화면 구석에 작게 잡힌다. 확대하면 화질이 깨져 올릴 수 없다."*
>
> 반대편 골밑에서 인물은 **280픽셀**입니다. 세로 숏폼에서 14.6%를 차지하는데, 이를 60%로 키우려면 **4.1배 확대**가 필요합니다. 가로 4K의 최대 배율은 **1.125배**입니다.

## 4-2. 그래서 실제로 가능한 것

| 확대 배율 | 반대편 골밑 인물 | 결과 |
| --- | --- | --- |
| 1.0배 (원본) | 14.6% | 누군지 알아보기 어려움 |
| **1.125배** (무손실 상한) | **16.4%** | 여전히 작음 |
| 2배 (2배 업스케일 감수) | 29.2% | 화질 저하 눈에 띔 |
| 4.1배 (목표) | 60% | **원본 대비 화질 1/4** |

# 5. 🟢 대응 방안 5가지

## ① 세로 촬영으로 전환 — **가장 효과적**

크롭 배율이 **1.125배 → 2.0배**로 78% 늘어납니다. 코드 변경 없이 **촬영 가이드만으로** 얻는 이득입니다.

| | 가로 촬영 | **세로 촬영** |
| --- | --- | --- |
| 크롭 여유 | 1.125배 | 🟢 **2.0배** |
| 15m 지점 인물 | 15.6% → 17.6% | 15.6% → **31.2%** |
| 🔴 **대가** | — | **담기는 폭이 0.844d로 축소** (15m에서 12.7m) |

> **트레이드오프** — 세로로 찍으면 15m 거리에서 폭 12.7m만 담깁니다. 코트 폭(15m)에 못 미쳐 **양 사이드가 잘립니다.** 코트 전체를 담으려면 17.8m 뒤로 가야 하는데 체육관에서는 불가능합니다.
>
> **→ "코트 전체"를 포기하고 "내가 있는 절반"만 담는 촬영을 안내하는 것이 실질적 해법입니다.**

## ② 목표를 "중앙 배치"로 낮추고 "확대"를 포기

Trace는 4X 줌으로 인물을 **크게** 만듭니다. 하일릿이 그걸 따라가면 집니다.

> **대신 "화면 중앙에 놓기"만 하면 1.0~1.125배로 충분합니다.** 코트 구석에 있던 인물이 화면 정가운데 오는 것만으로도 원본 대비 체감 차이가 큽니다.
>
> **소구 문구도 바뀝니다** — *"작게 잡힌 나를 크게"* ❌ → *"구석에 있던 나를 화면 중앙으로"* ⭕

## ③ 촬영 가이드에 구체적 수치를 넣는다

팀 확정 사항 *"촬영 여백은 앱 공지로 안내한다"* 에 넣을 실제 수치입니다.

```
권장:  세로로 세우고, 사이드라인에서 5~8m 이내
       코트 전체가 아니라 "내가 뛰는 절반"을 담을 것
한계:  10m를 넘으면 화면에서 23% 이하로 잡혀 확대가 어려움
       15m 이상은 결과물 품질을 보장할 수 없음
```

## ④ 4K 촬영을 필수로 안내

기본값이 1080p인 기기가 많습니다. **1080p면 크롭 여유가 0입니다**(세로 1080 = 출력 1080).

| 원본 | 세로 픽셀 | 크롭 여유 |
| --- | ---: | :---: |
| 1080p 가로 | 1080 | 🔴 **0배 — 확대 불가** |
| 4K 가로 | 2160 | 1.125배 |
| 4K 세로 | 3840 | 2.0배 |

## ⑤ AI 업스케일링은 마지막 수단

2배 업스케일까지는 AI로 어느 정도 복원되지만, **GPU 원가가 다시 올라갑니다.** Value Chain 분석이 지목한 *"성장이 곧 적자"* 구조와 정면으로 부딪힙니다.

# 6. 🔴 이 계산이 바꾸는 것

## 6-1. D1 차별점의 재정의

| | 기존 | **수정** |
| --- | --- | --- |
| D1 문구 | 추적한 결과로 화면을 다시 구성한다 | **이미 찍어둔 휴대폰 영상만으로 인물을 화면 중앙에 놓는다** |
| 소구점 | 구석의 나를 **크게** | 구석의 나를 **중앙으로** |
| Trace와의 관계 | 같은 일을 더 잘한다 ❌ | **같은 일을 하드웨어 없이 한다** ⭕ |

## 6-2. 페르소나별 영향

| 페르소나 | 촬영 거리 | 영향 |
| --- | --- | --- |
| **A-1 김도현** 코트 옆 삼각대 | 7~16m | 🟡 **절반만 유효** — 같은 쪽은 되고 반대편은 어렵다 |
| **D-1 강민석** 벤치 거치 | 10~20m | 🔴 **거의 불가** — 거리에 저조도까지 겹침 |
| **A-2 박서연** 사이드라인 | 5~15m | 🟡 조건부 |
| **A-4 서지훈** 체육관 고정 | 10~25m | 🔴 **40명이 흩어져 있어 대부분 원거리** |

> 🔴 **A-4(클럽)가 가장 타격이 큽니다.** 매출 경로인데 원생 40명이 코트 전체에 흩어져 있어 **대부분이 15m 이상**입니다. B2B로 가려면 **촬영 위치 가이드가 사실상 필수**이고, 그래도 안 되면 클럽에는 **광각 액션캠 권장**이 필요할 수 있습니다.
