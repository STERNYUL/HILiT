## 0. 왜 7차가 필요한가

**요금제는 "누가 돈을 내는가"를 정하는 문서다.** v3에서 그 답이 바뀌었는데 페르소나가 따라가지 않았다.

> 🔴 **v3의 개인 등급은 부계정 운영형이 아니라 학부모를 겨냥하고 있다.** 문서가 그렇게 쓰여 있다.

## 1. 🔴 요금제가 페르소나보다 앞서 나갔다

### 1-1. 개인 등급의 모든 신설 항목이 학부모를 향한다

| v3 신설·변경 | 누구를 향하는가 |
| --- | --- |
| **시즌권을 기본 결제 단위로** (39,000원 / 4개월) | 🔴 *"유소년 스포츠는 시즌제입니다. **학부모의 지불 인지 단위도 클럽 회비·대회·유니폼과 같은 시즌**입니다"* |
| **시즌 리캡 자동 생성** (개인 개방) | 🔴 *"효용의 정점을 시즌 말에 배치"* — 시즌 개념이 있는 사람 |
| **가족 공유** 1,900원/월 *(조부모·친척)* | 🔴 **A-5 문혜정 카드의 *"조부모에게 전달하기"*** 가 그대로 상품이 됐다 |
| **보관 30일 → 12개월** | *"누적 아카이브가 전환비용을 만든다"* — 시즌 단위로 쌓는 사람 |
| 브라우저 처리 시간 경고 | 🔴 문서가 직접 호명한다 — *"**학부모**가 브라우저 탭을 열어두고 기다려야 하는 시간"* |

### 1-2. 🔴 그런데 확정 6인에 학부모가 없다

| | 요금제 v3 | 페르소나 현황 |
| --- | --- | --- |
| 주 지불자 | **학부모** (시즌권·가족 공유·리캡) | 🔴 **확정 6인에 없다** |
| A-5 문혜정의 위상 | 개인 등급 설계의 근거 | ⏸️ **4순위 · 3명 · "수요의 증거"로 한정**(`06` 2-2절) |

> 🔴 **어제 A-5를 「수요의 증거」로 한정한 판단이 v3와 어긋난다.**
> `06` 2-2절은 *"A-5는 지불 주체가 아니다 — 매출은 A-4(클럽)가 만든다"* 고 썼다. **v3는 개인 등급을 학부모의 지불 단위에 맞춰 설계했다.** 즉 **학부모가 개인 등급의 지불 주체**다.
>
> 🔺 **둘 다 참일 수 있다** — 클럽(A-4)이 B2B 매출을, 학부모(A-5)가 개인 등급 매출을 만든다. **v3의 4등급 구조가 그것이다.** 다만 `06`의 문장이 *"지불 주체가 아니다"* 로 단정한 것은 정정해야 한다.

### 1-3. 조치 — A-5를 확정 구성에 넣는다

| | 기존 | **갱신** |
| --- | --- | --- |
| 확정 페르소나 | **6인** (C1·A1·E2·N1 + C4·E1) | **7인** — **A-5 추가** |
| A-5의 역할 | 수요의 증거 | 🔴 **개인 등급의 지불 주체** + 수요의 증거 |
| 인터뷰 순위 | 4순위 · 3명 | 🔺 **재검토 필요** — 개인 등급 매출의 근거라면 A-4·C1과 같은 층이다 |

🔴 **이 문서는 순위를 바꾸지 않는다.** JTBD 대상 순위는 `JTBD/01` 0-3절이 AOS/DOS로 정했고, **AOS/DOS 재산정이 이미 대기 중**이다(`docs/4-TAM-SAM-SOM-Market-Segment/03` 6-1절). **거기서 함께 정한다.**

## 2. 🔴 새 이탈 지점 — 편집이 아니라 대기다

**CLAUDE.md 규칙 4의 진단은 「편집 30분 초과 시 포기」였다.** v3가 실측을 가져왔다.

| 조건 | 20분 영상 처리 시간 |
| --- | ---: |
| 개발 PC CPU | **403초 = 6.7분** |
| 모바일 2배 느림 | **13분** |
| 모바일 3배 느림 | **20분** (실시간 배율 1.0) |
| 모바일 5배 느림 | 🔴 **34분** (실시간 배율 1.7) |

> 🔴 **편집을 0으로 만들어도 대기가 30분이면 같은 자리에서 이탈한다.**
> 규칙 4가 지목한 이탈 지점은 *"손이 가는 시간"* 이었는데, v3의 병목은 **손이 아니라 기다림**이다. **성격이 다르고 대응도 다르다** — 도구를 줄이는 것으로는 해결되지 않는다.
>
> v3도 같은 결론에 도달했다 — *"**「1편당 원본 20분」이라는 상품 표기 자체를 재검토해야 할 수도 있습니다.**"*

### 2-1. 🔴 이 축은 페르소나 전원에게 걸린다 — 다만 E2에게 가장 심하다

| 페르소나 | 단말 조건 | 예상 대기 |
| --- | --- | ---: |
| **E2 강민석**(D-1) | 🔴 **저사양** — 카드에 *"저사양 단말"* | 🔴 **34분 구간** |
| A-5 문혜정 | L1 · 기기 미상 | 13~20분 |
| C1 이준호 | L4 · 최신 기기 추정 | 6.7~13분 |

> 🔴 **E2의 역할이 하나 늘었다.** 종전에는 **성능 하한선**(탐지 정확도)을 정의했다. v3에서는 **대기 시간 하한선**도 정의한다.
> 🔺 **그리고 E2는 무료 등급 후보다** — 복구 상한이 10회라 *"어려운 영상은 Lv4 사용자 확인으로 넘어감"* 이다. **저조도·혼잡 영상에서 Lv4를 반복적으로 만나는 사람**이 된다.

### 2-2. 🔺 규칙 4를 다시 봐야 한다

CLAUDE.md 규칙 4는 어제 ADR-8 v1.9에 맞춰 개정했다. **v3는 또 다른 축을 추가한다.**

| 축 | 출처 | 상태 |
| --- | --- | :---: |
| 편집 도구 수 | 규칙 4 원판 | ✅ 반영됨 |
| 무료/유료 도구 배분 | ADR-8 v1.9 | ✅ 어제 반영 |
| 🆕 **처리 대기 시간** | **요금제 v3 · PoC §5.4** | 🔴 **미반영** |

🔺 **이 문서는 CLAUDE.md를 고치지 않는다** — 상품 표기(*"1편당 원본 20분"*) 재검토가 선행이고, 그건 요금제·SRS의 결정이다.

## 3. 위상이 바뀐 페르소나 4인

### 3-1. 🔴 A-5 문혜정 — 수요의 증거 → **원가의 절반을 만드는 사람**

v3 클럽 원가 구성이다.

| 항목 | 금액 | 비중 |
| --- | ---: | ---: |
| 🔴 **CS** | 12만원/년 | 🔴 **51.0%** |
| CAC + 온보딩 상각 | 66,667원 | 28.4% |
| 클라우드 | 39,150원 | 16.6% |
| Gemini·Haiku 처리 | 9,338원 | **4.0%** |

> 🔴 **v3가 못 박은 문장** — *"원가를 움직이는 건 CS(51%)이고 **CS는 아동 수·보호자 수에 비례**합니다."*
>
> 🔴 **A-5는 수요의 증거이면서 동시에 원가 동인이다.** 클럽 한 곳을 팔면 학부모 수십 명이 CS로 따라온다. **`06` 2-2절이 이 방향을 보지 않았다.**
>
> 🟢 **그래서 A-5 인터뷰의 목적이 하나 늘었다** — *"이 사람이 무엇을 문의하는가"* 를 알면 CS 원가를 줄일 수 있다. **총원가의 51%가 걸린 항목이다.**

### 3-2. 🔄 C2 김태윤 — 최대 시장 → **획득 채널**

v3 무료 등급에 **워터마크**가 신설됐다(720p · 워터마크).

> *"**무료 100명당 유료 2.06명**만 추천으로 들어와도 손해입니다. 추천율 실측 전까지 편수는 유지하고 첫 달 부스트만 줄입니다."*

| | 기존 판정 | **v3 이후** |
| --- | --- | --- |
| C2의 가치 | *"페인이 가장 크다 · 최대 시장"* | 🔄 **완주만 해도 확산에 기여한다** |
| 전환 여부 | 전환돼야 가치가 있다 | 🟢 **전환 안 해도 가치가 있다** |

> 🟢 **C2의 Job(JS-3)이 *"끝나기만 하면 됩니다"* 인데, v3는 끝나기만 해도 워터마크가 나간다.** Job과 사업 모델이 처음으로 맞물렸다.
> 🔺 **다만 추천율은 미실측이다**(v3 남은 결정 5번). 2.06명 문턱을 넘는지 모른다.

### 3-3. 🔄 N2 윤재석 — 설계 원칙 → **매출 조건**

N2는 *"디지털 리터러시 저층 · 제작 도구 접근 자체가 안 됨"* 이라 **설계 원칙으로만 흡수**됐다(`05` 5절).

**v3가 그를 매출 항목의 수령자로 만들었다.**

| | |
| --- | --- |
| 상품 | **가족 공유 1,900원/월** *(조부모·친척)* |
| 구매자 | A-5 학부모 |
| 🔴 **수령자** | **조부모** — 리터러시 조건이 N2와 겹칠 가능성이 높다 |

> 🔴 **조부모가 앱을 못 쓰면 1,900원이 안 팔린다.** 한계원가가 20원이라 마진 95.9%인 상품인데, **성립 조건이 N2의 온보딩 난이도**다.
> 🟢 **N2가 "비활성"에서 "매출의 전제"로 바뀐다.** 스펙트럼에 극단·비활성을 넣은 값이 여기서 또 나왔다.
>
> 🔺 **가족 공유의 수령 경로가 앱인지 링크인지 확인이 필요하다.** 링크로 보는 것이면 N2 조건이 크게 완화된다.

### 3-4. 🔺 C4 오세라 — Job이 상품이 됐다

C4의 Job(JS-4)은 *"3개월 전과 지금을 나란히 보고 싶다"* 였다.

| v3 항목 | 대응 |
| --- | --- |
| **보관 30일 → 12개월** | 🟢 *"누적 아카이브가 전환비용을 만든다"* — C4의 Job 그대로 |
| **시즌 리캡 자동 생성** | 🟢 JS-4의 *"계속하고 있다는 증거"* |
| 효용 레버 1순위 · 확신도 **높음** | 🟢 잔존 +0.14%면 본전 |

> 🟢 **C4는 「검증 전용」이었는데 v3에서 효용 레버 1순위의 근거가 됐다.** 위상을 올릴 근거가 생겼다.
> 🔵 **다만 `03` 7-2절이 요구한 「05 다시 열어보기」 화면이 여전히 없다.** **보관을 12개월로 늘려도 다시 볼 화면이 없으면 전환비용이 생기지 않는다.**

## 4. 🆕 신규 후보 — 리그·협회 운영자

v3가 **4번째 등급을 신설**했는데 페르소나가 없다.

| | |
| --- | --- |
| 등급 | **리그 · 협회** — 맞춤형 |
| v3 표기 | 🔴 **`단가 근거 미확보`** · *"지불 주체 · 계약 단가 조사 전"* |
| 페르소나 | 🔴 **없다** |

> 🔺 **지금 만들지 않는다.** v3 스스로 *"지불 주체 조사 전"* 이라 적었다. **누가 돈을 내는지 모르는 상태에서 페르소나를 만들면 그 페르소나가 조사 결과를 대신한다.**

## 7. 한 줄 결론

> **요금제 v3는 학부모를 주 고객으로 설계했는데, 페르소나는 어제까지 그를 조연으로 두고 있었다.** 시즌권·시즌 리캡·가족 공유·보관 12개월이 전부 A-5를 향한다.
>
> 🔴 **그리고 새 이탈 지점이 하나 생겼다** — 규칙 4가 지목한 것은 *"손이 가는 시간"* 이었는데, v3 실측의 병목은 **기다리는 시간(20~34분)** 이다. **편집을 0으로 만들어도 같은 자리에서 이탈한다.**
>
