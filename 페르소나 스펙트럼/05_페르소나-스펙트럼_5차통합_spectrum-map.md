## 2. 🔑 관계 구조 — 이 맵의 핵심

페르소나를 나열이 아니라 **서로에게 미치는 영향**으로 연결한 것이 5단계의 산출입니다.

```mermaid
graph TD
  A1["A1 서지훈<br/>유소년 클럽 코치"] -->|"클럽 1곳 = 원생 40 + 학부모 40가구"| A2["A2 문혜정<br/>학부모"]
  A1 -->|"원생이 자라서"| C1["C1 이준호<br/>부계정 운영형"]
  A1 ==>|"🟢 유일한 손익분기 경로<br/>클럽 320~630곳"| REV(("매출"))

  C1 -->|"결과물이 곧 광고"| C2["C2 김태윤<br/>편집에서 멈춘"]
  C1 -.->|"같은 코트, 다른 동기"| C4["C4 오세라<br/>안 올리는 아카이비스트"]
  C4 ==>|"🟢 아카이브 = 전환 비용"| RET(("리텐션"))

  N1["N1 조현아<br/>초상권 회피형"] ==>|"🔴 같이 뛰는 사람의<br/>전체공개를 막는다"| C1
  N1 ==> C2

  E2["E2 강민석<br/>최악 촬영 환경"] ==>|"🔴 여기서 실패하면<br/>대체재를 못 이긴다"| GATE(("정확도<br/>기준선"))
  E1["E1 임도현<br/>휠체어 농구"] ==>|"🔴 평가셋을 잘못 쌓으면<br/>배제가 고착"| DATA(("데이터<br/>자산"))

  style REV fill:#33FFBB,stroke:#333,stroke-width:2px
  style RET fill:#33BBFF,stroke:#333,stroke-width:2px
  style GATE fill:#FF3322,stroke:#333,stroke-width:2px
  style DATA fill:#FF3322,stroke:#333,stroke-width:2px
```

### 이 그림에서 읽어야 할 것 4가지

| # | 관계 | 함의 |
| --- | --- | --- |
| 01 | **A1 → 매출** | A1이 유일하게 손익분기에 닿는다. 개인 경로는 국내 농구 동호인 전체를 획득해도 미달(`04` 3절) |
| 02 | **C4 → 리텐션** | Five Forces "구매자 교섭력 강함"의 **유일한 완화 요인** |
| 03 | 🔴 **N1 → C1·C2** | 비활성 사용자가 **핵심 사용자의 발행률을 깎는다.** 화살표가 거꾸로 간다 |
| 04 | 🔴 **E2·E1 → 기준선** | 극단 사용자가 **성능·자산의 하한선을 정의한다.** 예외가 아니라 기준이다 |

> **③·④가 이 워크플로우를 스펙트럼으로 한 이유입니다.** 일반 페르소나 추출이었다면 N1·E1·E2는 뽑히지 않았고, **v1 발행률과 성능 기준선이 정의되지 않은 채로 진행됐을 것**입니다.

## 3. 4단계 흐름 위의 배치 — 누가 어디서 걸리나

```mermaid
graph LR
  S1["01 가져오기"] --> S2["02 트래킹 편집"] --> S3["03 장면 선택"] --> S4["04 기록 저장"] --> S5["05 다시 열어보기<br/>🔵 미설계"]

  N1x["N1 · 진입 전 거부"] -.-> S1
  E2x["E2 · 사전판정/오추적"] -.-> S2
  A1x["A1 · 1인칭 전제 위반"] -.-> S2
  C1x["C1 · 30개 훑기 피로"] -.-> S3
  C4x["C4 · 정렬 기준 불일치"] -.-> S3
  E1x["E1 · 후보에 내가 없음"] -.-> S3
  A1y["A1 · 선택이 노동"] -.-> S3
  C4y["C4 · 여기가 진짜 사용 시점"] -.-> S5

  style S3 fill:#FF3322,stroke:#333,stroke-width:3px
  style S5 fill:#DDDDDD,stroke:#333,stroke-width:2px,stroke-dasharray: 5 5
```

> 🔴 **「03 장면 선택」에 5명이 몰립니다.** 덱 13장이 *"사람은 정하기를 한다"* 를 단일 원칙으로 못 박았지만, 실제로는 **4가지 다른 요구**입니다 — 개수(C1) · 정렬 기준(C4) · 신뢰도(E2) · 자동화(A1). 그리고 E1은 후보에 아예 없습니다.
>
> 🔵 **「05 다시 열어보기」는 아직 설계되지 않았습니다.** C4의 진짜 사용 시점이고, KSF ④ 검증의 전제입니다.
