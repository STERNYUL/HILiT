# [부록 D] T2 검증 — B2B 모집단은 손익분기에 닿는가

| 항목 | 내용 |
| --- | --- |
| **검증 대상** | `부록B` T2 트리거 — *"유소년 농구 클럽 320곳 미만이면 테니스 전환 재검토"* |
| **왜 중요한가** | `04_4차검증` 4절 — **B2B가 유일한 손익분기 경로**. 개인 구독은 국내 농구 동호인을 100% 획득해도 미달 |
| **작성** | 2026-08-28 |

## 1. 확보한 수치

### 1-1. 🟢 체육교습업 — 유소년 스포츠 교습 시장이 급성장 중

| 항목 | 2022 | 2023 | 증감 |
| --- | ---: | ---: | ---: |
| **체육교습업** | 2,058개소 | **2,651개소** | **+28.8%** |
| 전체 체육시설업 | 60,644개소 | 64,378개소 | +6.16% |

> **체육교습업이 전체 체육시설업 성장률의 4.7배로 자라고 있습니다.** 유소년 스포츠 교습이 시장에서 가장 빠르게 커지는 구간이라는 뜻이며, **A1 페르소나의 시장 타이밍을 지지합니다.**

⚠️ **결정적 결측 — 2,651개소 중 농구 비중은 확인하지 못했습니다.** 종목별 분리 수치는 문체부 원자료 PDF에만 있습니다.

### 1-2. 🔴 성인 동호회 — 모집단은 크지만 **지불 의사가 미검증**

부록C에서 발견한 **플랜비**(농구 동호회 운영 매니저 — 멤버·팀편성·스탯·회비·전술보드)를 확인한 결과:

| 항목 | 실제 |
| --- | --- |
| 요금 | **전면 무료** |
| 결제·구독 | **제공하지 않음** |
| Pro 기능 | **관심 등록만 받는 중.** 50~100명 모이면 적용 검토 |

> 🔴 **동호회 운영 도구를 만든 사업자조차 유료화를 아직 못 하고 있습니다.** 그것도 유료 전환 검토 임계값을 **관심 등록 50~100명**이라는 매우 낮은 수준으로 잡아두고 있습니다.
>
> **부록C 5절에서 플랜비를 "동호회가 지출 주체라는 증거"에 가깝게 읽었는데, 정반대입니다.** 점유는 하고 있지만 수익화는 안 되고 있습니다.

## 2. 판정

### 2-1. 유소년 클럽 — 농구 비중에 따라 갈림

```
체육교습업 2,651개소 (2023) × 농구 비중 = 유소년 농구 클럽 수
```

| 농구 비중 | 클럽 수 | T2(320곳) |
| ---: | ---: | :---: |
| 5% | 133곳 | 🔴 미달 |
| 10% | 265곳 | 🔴 미달 |
| **15%** | **398곳** | 🟢 통과 |
| 20% | 530곳 | 🟢 통과 |

**성장률을 반영하면** (연 15% 보수 가정, 2023→2026):

```
2,651 × 1.15³ ≈ 4,030개소
```

| 농구 비중 | 2026 추정 | T2 |
| ---: | ---: | :---: |
| 10% | 403곳 | 🟢 통과 |
| 15% | 605곳 | 🟢 통과 |

> **판정 기준: 체육교습업 중 농구 비중이 10% 이상이면 T2 통과.**
> 유소년 교습 시장에서 태권도·수영·축구·농구·발레가 주요 종목인 점을 고려하면 10%는 불합리한 수치가 아니지만, **확인 전에는 판정할 수 없습니다.**

### 2-2. 성인 동호회 — B2B 모집단에서 **제외 권고**

| | 유소년 클럽 | 성인 동호회 |
| --- | --- | --- |
| 성격 | **사업체** (원생에게 수강료를 받음) | **비영리 모임** (회비로 운영) |
| 월 매출 | 원생 40명 × 15만원 ≈ **600만원** | 회원 20명 × 3만원 ≈ **60만원** |
| Veo 수준(연 190만원) 부담률 | 매출의 **2.6%** | 매출의 **26%** |
| 지불 의사 증거 | Veo 25,000 클럽 실증 | 🔴 **플랜비가 유료화 못 함** |

> **성인 동호회는 모집단이 크지만(추정 약 6,900곳) 지출 주체가 아닙니다.** B2B 매출 계산에서 제외합니다.
>
> ### 🔵 이것이 A1 페르소나의 정의를 좁혀줍니다
> **A1은 "클럽 운영자"가 아니라 "수강료를 받는 사업체 운영자"여야 합니다.** 동호회 총무는 같은 기능을 원하지만 돈을 내지 않습니다. 3단계 A1 카드의 *"유소년 클럽 대표 겸 코치 · 등록 원생 40명"* 설정은 이 기준에 부합합니다 — **유지가 맞습니다.**

### 2-3. 종합

> ## 🟡 **T2 = 보류 (미발동)**
> 발동시킬 근거도, 안심할 근거도 없습니다. **결정적 결측 하나**(체육교습업 중 농구 비중)로 판정이 갈립니다.
>
> **다만 방향은 긍정적입니다** — 시장이 연 28.8%로 자라고 있고, 성장을 반영하면 농구 비중 10%만 되어도 통과합니다.

## 3. 🔴 T2 트리거 자체를 재설계합니다

검증 과정에서 **T2의 설계 결함**이 드러났습니다.

| | 기존 T2 | **갱신 T2** |
| --- | --- | --- |
| 지표 | 유소년 농구 클럽 **320곳 미만** | **유소년 농구 클럽 10곳 인터뷰에서 "연 100만원 이상 지불 의사"가 30% 미만** |
| 성격 | 개수(모집단) | **지불 의사 × 침투 가능률** |
| 확인 방법 | 통계 조회 | 클럽 직접 접촉 |

**왜 바꾸나** — 클럽 수는 **도달 가능성의 대리 지표**일 뿐입니다. 진짜 변수는 *"그 클럽들이 돈을 낼 것인가"* 이고, 2-2절에서 본 대로 **모집단이 커도 지출 주체가 아니면 무의미**합니다. 플랜비 사례가 그 증명입니다.

**개수 기준은 보조 지표로 유지합니다** — 체육교습업 중 농구 비중 10% 미만이면 경고.
