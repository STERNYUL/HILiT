## 2. A1 · 서지훈 — 유소년 클럽 코치 `Adjacent 대표`

> **원생 40명과 학부모 40가구를 한 번에 데려오는 상위 노드.** 다만 하일릿의 4단계 흐름을 그대로 쓸 수 없다.

### 프로필

| | |
| --- | --- |
| 이름 / 나이 | 서지훈 / 38 |
| 직무 | 유소년 농구 클럽 대표 겸 코치 |
| 기술 수준 | **L2** — 기본 트리밍까지. 배울 의지는 있으나 시간이 없다 |

| 현재 처리량 | 아이별 편집 시 40명 × 3분 = **하루 2시간** → 실제로는 안 함 |

### 대표 인용구

> *"학부모가 원하는 건 우리 애만이에요. 40분 원본은 아무도 안 봐요."*

### Jobs to be Done

**수업이 끝났을 때**, 아이별 클립을 자동으로 학부모에게 보내고 싶다.
**그래야** 학부모가 성장을 눈으로 보고 재등록한다.

### 하일릿 사용 시나리오 — ⚠️ 현재 설계로는 3곳이 막힘

| 단계 | 이 사람의 실제 행동 | 설계 충돌 |
| --- | --- | --- |
| **01 가져오기** | 수업 종료 직후 체육관, 다음 타임까지 10분. 태블릿에서 40명 찍힌 영상 1개 | — |

### 남는 조건 / 떠나는 조건

| 남는다 | 떠난다 |
| --- | --- |

### 이 사람이 검증하는 것

**KSF ⑤ 좁은 카테고리에서 시작** — Hudl이 *"네브래스카 대학 한 팀 → 고등학교 → 미국 고교 98%"* 로 간 경로의 진입점이 정확히 이 사람입니다.
**KSF ③ 원가 설계** — 월 800건 규모라 단위 원가가 곧바로 손익에 반영됩니다.

### 과금 위치

월 약 800건 (40명 × 주 5일) → **B2B 요금제.** 2단계 C안에서 **원가 유발이 가장 큰 사람이 가장 많이 내는** 구조의 대표 사례입니다.
