## 6. 이 방식을 쓴 이유

일반 페르소나 추출은 "이상적인 주요 고객 1~3명"만 뽑습니다. 스펙트럼 방식으로 바꾼 결과 **일반 추출이었다면 나오지 않았을 두 가지**가 드러났습니다.

| 발견 | 함의 |
| --- | --- |
| 🔴 **N1(초상권 회피) → C1·C2** | 비활성 사용자가 **핵심 사용자의 발행률을 깎는다.** 화살표가 거꾸로 간다 |
| 🔴 **E2·E1 → 성능·자산 기준선** | 극단 사용자가 **하한선을 정의한다.** 예외가 아니라 기준이다 |

그리고 예상 못 한 수렴이 하나 있었습니다 — **E1(휠체어 농구)이 요구한 "종목 중립 설계"가, 카테고리 확정에서 "테니스 확장의 전제"로 다시 나왔습니다. 포용적 설계와 확장성이 같은 요구였습니다.**

## ⚠️ 전제와 한계

- 인물의 나이·직무·팔로워 수·시간 수치는 **가설**입니다. 확정 사항은 덱 명시분(40분 원본, 후보 30개 초안, 공개 범위 3단, 농구 우선, 앱 내 촬영 없음)과 선행 문서 수치뿐입니다.
- 농구 동호인 33만 명은 *"동호회 상위 5위 밖 = 6% 미만"* 이라는 **간접 근거의 상한 추정**입니다.
- TAM 문서에 수치 오류 2건을 발견해 지적했습니다 — **KRW 환산 10배 축소**, **전환율 5~20% vs 1~3% 불일치**(`02` 0-1절). 페르소나 범위 밖이라 수정하지 않았습니다.
