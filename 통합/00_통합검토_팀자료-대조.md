# 4. 🔴 실제 충돌 1건 — 내보내기

**두 자료가 정반대를 말합니다.** 이것만은 합칠 수 없어 판정이 필요합니다.

| | 팀 자료 (24장 확정) | 스펙트럼 (3단계 C3 카드) |
| --- | --- | --- |
| 판단 | **"만들지 않는다"** | **"없으면 C3는 진입조차 안 한다"** |
| 근거 | *"있으면 편집 앱으로만 쓰이고, HILiT은 SNS까지 가려는 서비스다"* | 인플루언서는 릴스·틱톡·쇼츠 3중 발행이 기본. 하일릿이 유일 발행처가 되는 일은 초기엔 없다 |
| 인물 | P2(부계정 운영자) → *"인스타그램 대신"* | C3 한지우 — 팔로워 6,200, 주 3~4회 |

### 판정 — 🟢 **팀 자료가 옳습니다. 단 조건이 붙습니다.**

**팀의 논리가 더 단단합니다.** Five Forces 분석이 도달한 결론과 같습니다 — *"편집 기능으로 수익을 설계하지 않는다. 값은 기록·관계·발견에서 나와야 한다."* 내보내기를 열면 하일릿은 **CapCut 대체재**가 되고, 그 시장은 무료 강자가 가격을 0원에 고정한 곳입니다.

**다만 스펙트럼이 지적한 위험은 실재합니다.** 그래서 조건을 답니다.

| # | 조건 | 이유 |
| --- | --- | --- |
| 01 | **C3(인플루언서)를 v1 타깃에서 제외** | 내보내기 없이는 진입하지 않는 층을 v1 지표에 넣으면 실패로 보인다. 팀 자료도 C부류를 *"확산 채널"* 로만 씀 — **일치** |
| 02 | 팀 자료의 미확인 항목 *"내보내기 없이도 인스타그램에서 옮겨올 사람이 있는지"* 를 **JTBD 문항으로 확정** | 이미 문항지에 있음 (C1-11) |
| 03 | 저장한 영상의 **기기 저장(다운로드)** 은 별개로 검토 | 내보내기 금지가 "내 영상을 못 가져간다"가 되면 신뢰 문제가 된다 |

# 6. ⭐ 통합 구조 — A·B·C·D 4부류 14명

팀 자료의 **A/B/C 부류 체계를 유지**하고, 스펙트럼의 극단·비활성을 **D부류로 신설**합니다.

```
A부류 · 원본 보유자 (4명)          B부류 · 일반 SNS 사용자 (3명)
├ A-1 김도현 26 · 농구 부계정  ⭐v1   ├ B-1 최윤아 19 · 계정 3개
├ A-2 박서연 22 · 풋살 촬영담당       ├ B-2 정민수 28 · 편집에서 멈춤 ⭐v1
├ A-3 이준혁 34 · 액션캠·저장공간     └ B-3 한지우 31 · 앱 4개 오감
└ A-4 서지훈 38 · 유소년 클럽 ⭐v1 🆕

C부류 · 크리에이터 (4명)           D부류 · 극단·비활성 (3명) 🆕
├ C-1 강태오 24 · 농구 크리에이터     ├ D-1 강민석 35 · 최악 촬영 환경 ⭐v1
├ C-2 서하린 27 · 필라테스 (v2)       ├ D-2 조현아 33 · 초상권 회피 ⭐v1
├ C-3 오세진 30 · 풋살팀 총무          └ D-3 임도현 19 · 휠체어 농구
└ C-4 윤가은 21 · 댄스 커버 (v2)
```

## 6-1. D부류를 넣는 이유

팀 자료의 A·B·C는 **"HILiT을 쓸 사람"** 만 다룹니다. D부류는 **"쓰지 못하거나 안 쓰는 사람"** 인데, 이들이 A·B·C의 성패를 좌우합니다.

| 인물 | 무엇을 정의하나 | 누구에게 영향 |
| --- | --- | --- |
| **D-1 강민석** | 🔴 **성능 하한선** — 야간·동일 복장·저사양에서 실패하면 무료 대안(원본 그대로 올리기)보다 못하다 | A부류 전체 |
| **D-2 조현아** | 🔴 **발행 임계** — 함께 뛴 사람 얼굴 때문에 A-1·B-2가 전체공개를 주저한다 | A-1·A-2·B-2·C-3 |
| **D-3 임도현** | 🔵 **데이터 자산의 편향** — 평가셋을 좋은 조건으로만 채우면 축적할수록 배제가 고착 | 전체 (v2 포함) |

> **D-2가 팀 자료의 공백을 정확히 메웁니다.** 박서연(팀원 8명)과 오세진(팀원 12명)은 **타인이 찍히는 영상**을 다루는데, 팀 자료에 초상권 항목이 없습니다. D-2가 그 질문을 제기합니다.

14명 전부를 v1에 쓰지 않습니다. **첫 종목 농구 + 검증 가치**로 좁힙니다.

| :---: | --- | --- | --- |
| **1** | **A-4 서지훈** | 클럽 | 🔴 유일한 매출 경로 · P-10 DOS 1.800 |

## 7-1. 🔴 편집 5단계에 대한 스펙트럼의 지적

팀 자료의 **3단계(사용자가 직접 고른다)** 는 훌륭한 설계 원칙이지만, 여정지도로 보면 **한 기능이 아니라 최소 4가지 요구**입니다.

| 인물 | 3단계에서 막히는 이유 | 필요한 것 |
| --- | --- | --- |
| A-1 김도현 | 지하철에서 한 손으로 30개는 많다 | **개수 조정** |
| B-1 최윤아 / C4 | "잘 나온 것" 순인데 "오늘 처음 된 것"을 찾는다 | **정렬 기준 선택** |
| D-1 강민석 | 후보에 다른 사람이 섞여 있다 | **신뢰도 표시** |
| D-3 임도현 | 후보에 내 장면이 아예 없다 | **저신뢰 구간 안전망** |
| A-4 서지훈 | 40명 × 30개 = 1,200개는 고를 수 없다 | **B2B 선택 자동화** |

> **"후보 30개"라는 숫자만으로는 다섯 사람을 다 만족시킬 수 없습니다.** 팀 자료도 30개를 *"약 30개"* 로 열어뒀으니, 이를 **4가지 하위 요구로 분해**하는 것이 다음 설계 과제입니다.

## 7-2. 🔵 편집 5단계 뒤에 빠진 것

**5단계(저장)가 끝이 아닌 사람이 셋 있습니다.**

| 인물 | 진짜 사용 시점 |
| --- | --- |
| A-1 김도현 | **다음 주 촬영** — 편집이 지치면 삼각대를 안 들고 간다 |
| A-4 서지훈 | **3개월 뒤 재등록 상담** — 성장 비교 자료 |
| B-1 최윤아 / C4 | **3개월 뒤 다시 열어보기** — 축적의 가치가 실현되는 지점 |

> **「6단계 · 다시 열어보기」가 필요합니다.** Strava의 유료 혜택이 *"같은 구간에서 내 기록이 시간에 따라 어떻게 변했는지"* 였고, Duolingo가 이탈률을 47%→28%로 낮춘 것도 축적을 눈에 보이게 만든 화면이었습니다.
